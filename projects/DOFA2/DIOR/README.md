# DOFA+ on DIOR

This project adapts the official DOFA+ large backbone to MMDetection for
DIOR object detection.

## Reference configuration

The public DOFA+ paper reports the following DIOR protocol:

- detector: Faster R-CNN;
- backbone: DOFA+ ViT-L, fully fine-tuned;
- epochs: 15;
- global batch size: 16;
- optimizer learning rate: 1e-4;
- evaluation metric: DIOR VOC-style mAP50.

The paper does not publish a standalone DIOR configuration file. The migration
therefore combines the public DOFAv2 backbone defaults with TerraTorch's public
object-detection path: native patch-14 embedding, transformer outputs
`[5, 9, 15, 21]`, RGB ImageNet normalization, a learned pyramidal projection,
and a normalization-free FPN. The 896-pixel input size is inherited from
TerraTorch's public DOFA detection example; it is not specified by the DIOR
paper. The schedule uses OneCycleLR and preserves the public example's two
warm-up epochs within the paper's 15-epoch duration.

With four GPUs, `batch_size=4` per GPU gives the paper's global batch size 16.
The backbone is not frozen. The paper-style run trains on all 11,725
train+val images by concatenating the official `train.txt` (5,862 images) and
`val.txt` (5,863 images) splits. It does not run validation on `val.txt`,
because those images are part of the training set. The held-out 11,738-image
test split is evaluated from the final epoch-15 checkpoint.

## Fixed server paths

- Dataset: `/mnt/ht2-nas2/EO_test/openmmlab-archive/dat/DIOR/`
- Checkpoint:
  `/mnt/ht2-nas2/EO_test/openmmlab-archive/pretrained/dofav2_vit_large_e150.pth`

The dataset configuration uses the real DIOR split layout:

- train: `Images/trainval` + `ImageSets/Main/trainval.txt`, generated by
  concatenating `ImageSets/Main/train.txt` and `ImageSets/Main/val.txt`;
- validation: disabled for the paper-style trainval protocol;
- test: `Images/test` + `ImageSets/Main/test.txt`.

If the distributed DIOR package does not include `trainval.txt`, create it once
inside `ImageSets/Main`:

```bash
cat train.txt val.txt > trainval.txt
```

## Training and testing

Use MMDetection's existing distributed scripts from the repository root:

```bash
bash tools/dist_train.sh \
  projects/DOFA2/DIOR/configs/dior_dofav2_vit-large-e150_faster-rcnn_e15.py \
  4
```

For eight A100 GPUs, the dedicated configuration fixes the per-GPU batch size
at 4, uses FP16 mixed precision with dynamic loss scaling, and linearly scales
the peak learning rate to 2e-4 for global batch size 32:

```bash
bash tools/dist_train.sh \
  projects/DOFA2/DIOR/configs/dior_dofav2_vit-large-e150_faster-rcnn_8xb4_fp16_e15.py \
  8
```

```bash
bash tools/dist_test.sh \
  projects/DOFA2/DIOR/configs/dior_dofav2_vit-large-e150_faster-rcnn_e15.py \
  /path/to/epoch_15.pth \
  4
```
